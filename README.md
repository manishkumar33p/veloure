# VELOURE LUX — Premium React Storefront

## Run locally
1. Extract this folder and open it in VS Code.
2. Run `npm install`
3. Run `npm run dev` (or `npm start`)
4. Open the Local URL shown in terminal.

## WhatsApp
Copy `.env.example` to `.env` and set `VITE_WHATSAPP_NUMBER` to your country code + number without `+` or spaces, e.g. `919876543210`. Restart the dev server after changing it.

## Important
This is a frontend demo. Product data and imagery are sample content. Orders/dashboard are saved only in the current browser using localStorage. WhatsApp checkout opens a pre-filled chat; it does not process online payments. Add a secure backend/Firebase and a payment provider before accepting real orders. Replace placeholder phone, Instagram and product claims with verified business details.
